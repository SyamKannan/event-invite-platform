# Images

Drop your photos here, then reference them in `src/config/wedding.config.js` as `/images/your-file.jpg`.

The hero background and gallery default to remote Unsplash placeholders so the site works out of the box — replace them with your own.

Recommended:
- Hero: 1920×1280, JPG/WebP, < 400 KB
- Gallery: 1200×1500 or 1500×1000, JPG/WebP, < 250 KB each
