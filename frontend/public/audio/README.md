# Music

Background music is uploaded per invitation from the admin editor
(Contact tab → "Background music"), stored on the uploads disk, and served
from the API — nothing needs to live in this folder.

Recommended for uploads:
- Format: MP3 or M4A (max 15 MB)
- Length: 1–3 minutes (the player loops)
- Volume-normalized so it does not startle visitors
- Royalty-free or licensed for personal use
